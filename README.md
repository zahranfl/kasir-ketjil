# kasir-ketjil

Aplikasi kasir sederhana berbasis PHP procedural + MySQL.

## Fitur
- Login system
- Manajemen produk (CRUD)
- Manajemen pelanggan (CRUD)
- Manajemen barang masuk (CRUD)
- Manajemen pesanan (tambah, edit, hapus item)
- Stok otomatis update

## Cara Install

1. Clone repository ini
2. Pindahkan folder ke `htdocs` (XAMPP) atau `www` (Laragon)
3. Buka phpMyAdmin, buat database `kasir`
4. Import file `kasir.sql`
5. Buka browser: `http://localhost/kasir-ketjil/login.php`

## Default Login
- Username: admin
- Password: admin
